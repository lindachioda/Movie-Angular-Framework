## 🎞️ Movie Blog ##
Starting from the provided `db.json` file, build a movie management application with multiple accessible pages.

The application should include:

*  A login area for user authentication
*  A movie section where users can browse and manage movies
*  A dedicated section where users can view the available users
*  Integration of a framework of your choice, making extensive use of its features and components
